# アプリ仕様書：PhotoMap

**バージョン：** 1.3（実装準拠）  
**最終更新：** 2026年5月15日  
**対象プラットフォーム：** Web / Android / iOS（PWA）

---

## 1. プロジェクト概要

**PhotoMap** は、写真をアップロードすると EXIF 等から位置情報を取得し、地図上にスポット（ピン）として表示する Web アプリである。同一スポットの写真は1つのピンに集約され、ズームや近接度に応じて `Leaflet.markercluster` によりクラスタ表示される。

- プロダクト名（UI 表示）：**PhotoMap**
- 認証済みユーザーのみが地図・ギャラリー・アップロード等の主要機能を利用（ミドルウェアで保護）
- 地図データは **全件スナップショット（最大500スポット）＋クライアント側の表示範囲フィルタ** で運用し、パン・ズームのたびに API を叩かない

## 2. 技術スタック

| 項目 | 技術 | 備考 |
|------|------|------|
| フレームワーク | Next.js（App Router） | React Server / Client Components |
| 言語 | TypeScript | |
| 地図 | Leaflet.js + OpenStreetMap | タイルは OSM |
| クラスタリング | Leaflet.markercluster | `maxClusterRadius: 42` 等 |
| 逆ジオコーディング | Nominatim（`lib/geocode.ts`） | アップロード時のスポット名推定 |
| 認証 | NextAuth.js | Google OAuth + メール/パスワード（Credentials） |
| データベース | Supabase（PostgreSQL + PostGIS） | |
| ストレージ | Supabase Storage（`photos` バケット） | 署名付き URL で配信 |
| 画像処理 | sharp | サムネイル生成等 |
| PWA | next-pwa | `manifest.json` / Service Worker |
| ホスティング | Vercel（想定） | 商用・広告時は Pro プラン推奨（§9 参照） |

> Nominatim は利用規約上 1 req/sec 程度を目安とする。高トラフィック時は自己ホストまたは代替 API を検討。

## 4. 認証・アクセス制御

### 4.1 ログイン方式

| 方式 | 説明 |
|------|------|
| Google OAuth | `GoogleProvider` |
| メール + パスワード | `CredentialsProvider` + Supabase Auth |
| 新規登録 | `/register` → `/api/auth/register` |

環境変数 `ALLOWED_EMAILS`（カンマ区切り）が設定されている場合、**許可メールアドレスのみ**ログイン可能。

### 4.2 ミドルウェア（`middleware.ts`）

- **公開パス：** `/login`, `/privacy`, `/api/auth/*`
- **上記以外のページ・API：** JWT 未所持時は `/login` へリダイレクト（API は 401 JSON）
- 静的アセット（画像・SVG・`_next` 等）は除外

### 4.3 プロフィール（`users` テーブル）

| 項目 | 説明 |
|------|------|
| 表示名 | `display_name`（Google 名で初期化可） |
| ユーザー名 | `username`（3〜30文字、英数字と `_`、一意） |
| 自己紹介 | `bio`（最大200文字） |
| 主な活動場所 | `primary_location`（自由テキスト） |
| アバター | `avatar_url`（Storage `avatars/{userId}/...`、最大2MB） |

編集 UI：`/profile/edit`（`PATCH /api/me/profile`、FormData）。

- 白背景、高さ `h-16`（4rem）

### 5.2 フッターナビ（`BottomNav`、モバイル中心）

固定下部、白背景、アイコンは `public/icons/` の SVG。

| タブ | リンク | アイコン |
|------|--------|----------|
| Map | `/` | `map_24dp_...` |

| Profile | `/profile` | `person_24dp_...` |

アクティブタブは薄緑ピル（`#bbf7d0`）で表示。

### 5.3 プロフィールページ専用ヘッダー（`ProfilePageTopNav`）

- デスクトップ（`md+`）：中央に Map / Gallery / Upload / **Profile**（Profile に青下線）

| 定数 | 用途 |
|------|------|
| `APP_MAIN_TOP_CLASS`（`pt-20`） | 固定ヘッダー下の main 上余白 |

地図トップ（`/`）は全画面地図のため main 余白は最小。コンテンツページ（アップロード・プロフィール等）は上記を適用。

## 6. 機能仕様

### 6.1 地図（メイン `/`）

**コンポーネント：** `HomePageClient` + `MapViewClient`

#### データ取得

1. 初回表示時、スナップショットが無ければ `refreshAllSpotsSnapshot()` で **全世界 bounds** のスポットを一度取得（API 上限 **500件**）。
2. パン・ズーム時は `filterSpotsInBounds()` でクライアントフィルタのみ（**API 再取得なし**）。
3. **アップロード完了後**・**写真削除後**に `refreshAllSpotsSnapshot()` で全件再取得。

実装：`lib/spotsBoundsCache.ts`、API `GET /api/spots?bounds=...&zoom=...`

#### クラスタリング・操作

- `L.markerClusterGroup`：`maxClusterRadius: 42`、`zoomToBoundsOnClick: false`、`spiderfyOnMaxZoom: false`
- ピンアイコン：共通 `/map-pin.svg`
- **クラスタクリック：** 複数スポット ID を `cluster:spots~{id1}~{id2}~...` 形式で `/gallery/[id]` へ遷移
- **単一ピンクリック：** 該当スポットの `/gallery/[spotId]`
- 初回位置：localStorage `home:lastView` → GPS → IP 位置（フォールバック）
- 右下 FAB：現在地（`my_location` アイコン）、アップロードへ遷移

#### 表示モードラベル

ズームに連動して内部 `displayMode`（world / country / region / prefecture / city / spot / detail）を更新し、UI ラベル表示に利用。**集計単位の切替 API はなく、常にスポット単位データを表示する。**

| ズーム目安 | ラベルモード |
|-----------|-------------|
| ≤3 | world |
| 4–6 | country |
| 7–9 | region |
| 10–12 | prefecture |
| 13–15 | city |
| 16– | detail / spot |

---

### 6.2 画像アップロード（`/upload`）

**フロー（ステージ）：** `select` → `review` → `uploading` → `done`

1. 複数ファイル選択（JPEG / PNG / HEIC / WebP、**1ファイル最大20MB**）
2. クライアントで EXIF GPS 抽出（`lib/exif.ts`）。GPS 無しはレビューに進めない
3. 逆ジオコーディングで地名候補、地図カードで位置確認
4. `POST /api/photos/upload`：Storage 保存 + DB 登録 + スポットマッチ（`lib/spotMatcher.ts`、半径 **50m** 目安）
5. 完了モーダル（`UploadResultModal`）、Tips 表示（`data/tips.json` / `TipsCard`）
6. 完了後 `refreshAllSpotsSnapshot()` で地図用キャッシュ更新

公開設定：`is_public`（実装ではデフォルト公開）。

---

### 6.3 ギャラリー（`/gallery/[id]`）

| `id` の種類 | 挙動 |
|-------------|------|
| スポット UUID | 単一スポットの写真一覧（`GalleryClient`） |
| `cluster:spots~...` | 複数スポットの写真マージ表示（`MergedSpotsGalleryClient` / `ClusterGalleryClient`） |

- 初回画像読み込みまでローディング（ドットアニメ + Tips）
- カード日付：**撮影日 `taken_at` 優先**、無ければ `created_at`（`lib/galleryPhotoDate.ts`）
- 選択モード・一括削除・ZIP 等（既存ギャラリー UI）
- 写真削除後は `refreshAllSpotsSnapshot()` を呼ぶ

関連 API：

- `GET /api/spots/[id]/photos`
- `GET /api/photos/by-spots?ids=...`
- `GET /api/photos/in-bounds?bounds=...`（クラスタ用）

---

### 6.4 プロフィール（`/profile`）

`/me` は `/profile` へリダイレクト。

| セクション | 内容 |
|-----------|------|
| ヒーロー | グラデーション背景、アバター、表示名、Edit Profile、自己紹介 |
| 統計 | Total Photos / Places Visited / Member Since |
| タブ | Gallery・Favorites・Maps |
| Recent Uploads | 自分の写真グリッド（ライトボックス・削除可） |
| Favorite Locations | スポット別集計カード（写真枚数・カバー画像、`/gallery/[spotId]` へリンク） |
| Maps タブ | 地図ページへの導線 |

データ：`GET /api/me/profile`、`GET /api/me/photos`（クエリ `q`, `from`, `to`, `visibility` 対応）。

---

### 6.5 プロフィール編集（`/profile/edit`）

モック準拠のフォーム UI（英語ラベル）：

- Change Photo（最大2MB）
- Full Name / Username / Short Bio（200文字）/ Primary Location
- Cancel → `/profile`、Save Changes → `PATCH /api/me/profile`

---

### 6.6 設定（`/settings`）

- テーマ：システム / ライト / ダーク（`ThemeProvider`）
- プロフィール編集へのリンク
- アカウント削除：`DELETE /api/me/account` → サインアウト

### 6.7 スポット詳細（`/spot/[id]`）

## 8. データモデル

### users

| カラム | 型 | 説明 |
|-------|----|------|
| id | UUID | PK（NextAuth の sub 等） |
| email | VARCHAR | 一意 |
| display_name | VARCHAR | 表示名 |
| username | VARCHAR | ユーザー名（一意、小文字化） |
| bio | TEXT | 自己紹介 |
| primary_location | TEXT | 主な活動場所 |
| avatar_url | TEXT | Storage パスまたは URL |
| created_at | TIMESTAMPTZ | 作成日時 |

マイグレーション：`001_initial_schema.sql`、`002_users_profile_fields.sql`

### spots

| カラム | 型 | 説明 |
|-------|----|------|
| id | UUID | PK |
| name | VARCHAR | スポット名 |
| location | GEOMETRY(Point, 4326) | PostGIS |
| address | TEXT | 住所 |
| created_at | TIMESTAMPTZ | |

### photos

| カラム | 型 | 説明 |
|-------|----|------|
| id | UUID | PK |
| user_id | UUID | FK → users |
| spot_id | UUID | FK → spots |
| storage_url | TEXT | 原画パス |
| thumbnail_url | TEXT | サムネイルパス |
| is_public | BOOLEAN | 公開フラグ |
| taken_at | TIMESTAMPTZ | 撮影日時（EXIF 優先） |
| created_at | TIMESTAMPTZ | 投稿日時 |
| exif_lat / exif_lng | DOUBLE | EXIF 座標（保持） |

## 9. API エンドポイント

| メソッド | パス | 説明 |
|---------|------|------|
| POST | `/api/photos/upload` | アップロード・スポット紐付け |
| GET | `/api/spots` | bounds 内スポット（地図用、最大500件） |
| GET | `/api/spots/[id]` | スポット詳細 |
| GET | `/api/spots/[id]/photos` | スポットの写真一覧 |
| GET | `/api/photos/in-bounds` | 矩形範囲内の写真 |
| GET | `/api/photos/by-spots` | 複数スポット ID の写真 |
| PATCH | `/api/photos/[id]` | 公開設定変更 |
| DELETE | `/api/photos/[id]` | 写真削除 |
| GET | `/api/me/photos` | 自分の投稿一覧（フィルタ可） |
| GET | `/api/me/profile` | プロフィール取得 |
| PATCH | `/api/me/profile` | プロフィール更新（FormData） |
| DELETE | `/api/me/account` | アカウント削除 |
| GET | `/api/geocode/reverse` | 逆ジオコーディング |
| POST | `/api/auth/register` | 登録 |
| POST | `/api/auth/reset-password` | パスワードリセット |

認証 API は NextAuth の `/api/auth/[...nextauth]`。

## 10. 非機能要件

| 項目 | 要件 / 実装 |
|------|------------|
| 地図マーカー | スナップショット方式でパン時 API なし。初回・更新時のみ取得 |
| 地図スポット上限 | DB / API：**500件**（超過分は地図に出ない） |
| 画像上限 | 20MB / ファイル |
| 対応形式 | JPEG, PNG, HEIC, WebP |
| アバター上限 | 2MB |
| ストレージ配信 | 署名付き URL（`createSignedPhotoUrl`） |
| PWA | Service Worker、オフラインページ |
| セキュリティ | HTTPS、ミドルウェア認証、Storage 署名 URL |
