地図ビュー実装ドキュメント

対象: components/Map/MapView.tsx / components/Map/MapViewClient.tsx
生成日: 2026-05-14（コードベースに基づく）

1. 概要

スポットを Leaflet と react-leaflet で地図上に表示し、 表示範囲（バウンディングボックス）とズームに応じて GET /api/spots からデータを取得するクライアントコンポーネントです。 マーカーは leaflet.markercluster でクラスタリングし、ズーム 12 以上では個別ピン表示に切り替わります。

2. エントリ: MapView

next/dynamic で MapViewClient を遅延読み込みし、ssr: false に設定しています。 Leaflet はブラウザ DOM に依存するため、サーバー側ではレンダリングせず、ロード中はプレースホルダーを表示します。 

const MapViewClient = dynamic(() => import("./MapViewClient"), {
  ssr: false,
  loading: () => <div className="..." />,
});

3. データ型

SpotMapItem

API から受け取るスポットの地図用スキーマです。

フィールド型説明
idstringスポット ID（クリックで /gallery/[id] へ遷移）
namestring名称
addressstring | null住所
lat / lngnumber緯度・経度
photo_countnumber写真枚数
thumbnail_urlstring | nullサムネイル URL

DisplayMode

ズームレベルから導出される「表示モード」ラベル用の列挙です。

world | country | region | prefecture | city | spot | detail

4. MapViewClient の props

prop説明
queryオプション。トリム・小文字化後、名称・住所に部分一致するスポットだけマーカー更新対象にする。
showInternalControlsデフォルト true。ズームプリセットボタンと表示モード表示の表示切替。
requestedZoom地図準備後に setZoom する外部指定ズーム。
locateSignal変更時に現在地取得して地図を合わせる（ズームは既存と 14 の大きい方）。
initialCenter / initialZoom初期中心・ズーム。無効時は localStorage または東京フォールバック。
recenterSignal変更時に initialCenter と initialZoom で setView（アニメーションなし）。
onViewChange移動・ズーム終了時に { lat, lng, zoom } を親へ通知。
mapWrapClassName地図ラッパーのクラス。未指定時は h-[62vh] 等のデフォルト。

5. ref（MapViewHandle）

  • setZoom(zoom: number) — 現在の地図インスタンスへズーム設定。
  • locate() — Geolocation API で現在地へ移動（ズームは max(現在, 14)）。

6. 永続化: home:lastView

readPersistedHomeView() が localStorage キー home:lastView から { lat, lng, zoom } を読み込みます。数値検証とズームのクランプ（2〜18）を行います。 MapContainer の初期 center / zoom および onMapReady 内の初回 setView に利用されます。

7. URL クエリ（フォーカス・デバッグ）

パラメータ用途
spot_idデバッグ表示やアップロード後の文脈用。詳細パネルの自動オープンは意図的に行わない（コメント記載）。
lat, lng, zoom数値として有効な場合、別 useEffect で setView 後に fetchSpots を二重 requestAnimationFrame 経由で実行。
debug1, true, 空文字, yes のいずれかでコンソールログと画面左下デバッグパネル表示。

8. スポット取得 API

クライアントは fetch(`/api/spots?${params}`, { cache: "no-store" }) を呼び出します。

  • bounds: south,west,north,east（5 桁固定小数でキー化し重複取得を抑制）
  • zoom: 現在のズームレベル

サーバー側（app/api/spots/route.ts）はセッション必須（未ログインは 401）、 get_spots_in_bounds RPC で範囲内スポットを取得する構成です。

9. 取得のスロットリング・重複防止

  • 同一 fetchKey かつ直近 700ms 以内の再実行はスキップ。
  • 同一キーで進行中のリクエストがあればスキップ。
  • 成功時に lastFetchKeyRef を更新。

10. マーカーとクラスタ

  • 共有アイコン getMarkerIcon(): /map-pin.svg、サイズ 40×40、アンカー・ポップアップ位置を固定。
  • L.markerClusterGroup: disableClusteringAtZoom: 12、maxClusterRadius: 24、spiderfyOnMaxZoom: true。
  • clusterclick で zoomToBounds または spiderfy を呼び、ギャラリー URL への誤遷移を防止。
  • 個別マーカーの click で router.push(`/gallery/${spot.id}`)。

11. 都道府県境界（GeoJSON）

外部 GeoJSON（PREF_BORDERS_URL）を cache: "force-cache" で取得し、 react-leaflet の GeoJSON で描画します。 ズーム 6 未満では非表示。線の weight / opacity は現在ズームに応じて変化します。

12. タイルレイヤ

OpenStreetMap Japan のタイル（{s}.tile.openstreetmap.jp、サブドメイン a/b/c）とクレジット表記を使用しています。

13. 子コンポーネントの役割

コンポーネント役割
MapEventBridgemoveend / zoomend でバウンド変更時に fetchSpots、任意で onViewChange。
MapInitializerマウント時に onReady(map) を一度呼び、クラスタ初期化と初回取得を実行。
ModeSynczoomend と初回で親の表示モード状態を同期。

14. その他の挙動

  • ResizeObserver: ラッパー要素のリサイズ時に map.invalidateSize({ pan: false })。
  • アンマウント: クラスタレイヤを地図から除去。
  • ポップアップ: 意図的に未使用（コメントで明記）。
  • 表示モードボタン: 世界(2) / 国(5) / 地方(8) / 県(11) / 市(14) の固定ズームへジャンプ。
