# テスト方針（E2E / 統合）

## 目的

- 主要ユーザーフロー（公開ページ閲覧、認証導線、保護ルートの挙動）の回帰を防ぐ
- リリース前に最低限の動作保証を自動化する

## テストレイヤー

- **E2E（Playwright）**
  - `tests/e2e/core-flows.spec.ts`
  - 対象:
    - ホーム・プライバシー・オフラインページ表示
    - ログイン/登録ページ表示
    - 保護ルート（`/upload`）未ログイン時の遷移
- **統合テスト（今後拡張）**
  - API Route Handlers 単位で、認証・権限・フィルタ・ページネーションを検証
  - 将来的に `vitest` + `supertest` 相当の構成を追加

## 実行方法

```bash
npm run test:e2e
```

## 今後追加する主要ケース

- 画像アップロード成功/失敗（GPSあり・手動入力）
- マイページで公開設定切替・削除
- スポット詳細で公開/非公開写真の可視性制御
